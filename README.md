# Brass di Lovers – Alpine Brass Website

Eine responsive HTML-Demo auf Basis der freigegebenen grafischen Designvorschau. Navigationsmenü, Unterseiten, Termine, Formulare und Links sind echte HTML-Elemente. Gestaltungsbestandteile werden als eigenständige lokale PNG-/WebP-Dateien geladen.

## Deployment
Static website / GitHub main -> Cloudflare Pages. Kein Build, Ausgabeverzeichnis `/`.
