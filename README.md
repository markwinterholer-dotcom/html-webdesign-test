# Brass di Lovers – „Blech trifft Beats“ (Design-Demo)

A fully responsive static HTML/CSS/JS demo for an eight-piece brass-focused band based in Murau and Murtal. The creative direction combines the heritage of real brass instruments with pop, rock and dance music through a warm cream / deep petrol / brass-gold / coral visual identity.

## Files
- index.html, ueber-uns.html, termine.html, medien.html, galerie.html, kontakt.html, impressum.html, datenschutz.html
- assets/style.css
- assets/script.js

## Deployment
No build step. Cloudflare Pages serves the repository root on the main branch.
