# Brass di Lovers – Unkonventionelles Collage-Webdesign

„Blech. Beats. Bam!“ – responsiver HTML/CSS-Prototyp mit asymmetrischer Bildkomposition, schrägen Headlines, diagonalen Bändern und transparent markierten Symbolfotos. Der Nutzer lieferte ein Konzertplakat ausschließlich zur Bandidentifikation. Das Plakat selbst wurde **nicht** als Hintergrund oder Template übernommen.

## Live / Dateien
Static HTML: index.html, ueber-uns.html, termine.html, medien.html, galerie.html, kontakt.html, impressum.html, datenschutz.html, assets/style.css, assets/script.js. Deploy via Cloudflare Pages (main, no build, root).
