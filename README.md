# Brass di Lovers – moderne responsive HTML-Demo

Redesign: Dark editorial visual identity, acid-yellow accents, bold Barlow Condensed headlines, responsive navigation, editorial photo sections and live-calendar placeholder.

## Deployment
Static website: index.html, assets/style.css and assets/script.js. GitHub main -> Cloudflare Pages (no build required, root output directory).

## Demo limitations
- All music and band photos are stock/symbol images, **not photographs of the actual group**. Images are externally loaded from Unsplash.
- Calendar does not claim confirmed real performances.
- Contact form copies an inquiry to clipboard and does not submit to a server.
- Impressum and Datenschutz are placeholders, require legal review and official data.
- External Google Fonts/Unsplash calls should be reviewed or self-hosted for real production.
